Configuración Firebase

Crea un proyecto en Firebase Console, activa Firestore Database y pega aquí la configuración web (Project settings → Your apps → Config).

Reglas Firestore recomendadas (chat + usuarios) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /registrations/{docId} {
      allow read: if true;
      allow create, update: if request.resource.data.keys().hasAll(['nombre','apellidos','telefono','registeredAt']);
    }
    match /activity/{docId} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasAll(['t','msg']);
    }
    match /chat/{docId} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasAll(['user','text','t'])
                    && request.resource.data.text is string
                    && request.resource.data.text.size() <= 500;
      allow update, delete: if false;
    }
  }
}

Pégalas en Firebase Console → Firestore → Rules → Publicar.

Galería

Añade fotos desde el móvil o el ordenador. También puedes pegar URLs abajo.

Las fotos se guardan en la app y, si GitHub está configurado, se publican en data.json. La app conserva una copia de respaldo y protege la galería cuando se guardan otros cambios. Usa imágenes no demasiado pesadas.

Asistente IA del club

Escribe en lenguaje natural para consultar o modificar datos de la app (próximo partido, resultados, etc.).

Ejemplos: "¿cuál es el próximo partido?", "cambia la fecha a 2026-09-13", "añade noticia: Nuevo entrenamiento el viernes", "ayuda"

Publicar cambios a todos (GitHub)

Configura esto una vez en tu móvil. A partir de ahí, cada vez que pulses "Guardar" en cualquier pestaña, la app escribirá directamente el archivo data.json en tu repositorio de GitHub, y todos los que abran la app verán el cambio.

Avisos push (OneSignal)

Para que los avisos funcionen hacen falta dos cosas:
1) Cada socio pulsa Activar avisos en el menú (y acepta el permiso).
2) Tú pegas aquí la REST API Key (OneSignal → Settings → Keys & IDs) y guardas.
También el dominio de la app debe estar en OneSignal → Settings → Platforms → Web (URL de GitHub Pages).
