LOS MORRUOS - FIREBASE CONFIGURADO

Se ha integrado la configuración web de Firebase proporcionada para que la
aplicación use el proyecto compartido "los-morruos" en lugar de depender de
una configuración introducida manualmente en cada móvil.

IMPORTANTE:
- La lista de usuarios solo será compartida si Firebase Authentication /
  Firestore (o la base de datos que usa el código) tiene sus reglas y
  colecciones configuradas correctamente.
- La apiKey web de Firebase no es una contraseña privada; aun así, las reglas
  de Firebase deben proteger correctamente los datos.
- Después de subir los archivos, hay que recargar/borrar caché de la PWA.

Se validaron los bloques JavaScript embebidos sin errores de sintaxis.
